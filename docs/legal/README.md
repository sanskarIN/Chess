# Legal and distribution documentation

This directory turns repository claims into release checks. It is written for
maintainers and distributors, not as individualized legal advice.

- [Dependency and notices process](dependency_audit.md)
- [Stockfish distribution obligations](stockfish_distribution.md)
- [Release legal checklist](release_legal_checklist.md)
- [Privacy data map](privacy_data_map.md)

Repository-level authoritative documents are LICENSE, COPYRIGHT, NOTICE,
THIRD_PARTY_NOTICES.md, PRIVACY.md, TERMS.md, and SECURITY.md.

The current repository contains no release APK/AAB and no Stockfish binary.
Legal documents must be reconsidered whenever code, dependencies, assets,
hosting, data behavior, store declarations, or distribution territories change.
