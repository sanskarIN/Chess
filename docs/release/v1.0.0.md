# Chess-Master 1.0.0: first stable source release

Released source version: `1.0.0+13`, Git tag `v1.0.0`.

Website and contact: <https://sanskarin.github.io>

## What this release contains

This is a stable **source-only** release of the twelve-phase Chess-Master
implementation, not an owner-signed Android application distribution. GitHub's
source ZIP/tar archives contain the Flutter Android app, optional self-hosted
relay, tests, documentation, license notices, and locked dependency manifests.
The separately attached CycloneDX SBOM inventories source dependencies only.

- Complete chess rules, FEN/PGN, promotion, castling, en passant, and draws.
- Offline computer matches with four bounded difficulty levels, local
  two-player chess, clocks, board rotation, undo/redo, draw offers, and rematches.
- Optional friend play through a configured memory-only WebSocket relay, with
  temporary room codes, legal move validation, state checks, and reconnects.
- Daily challenges, local coins and hints, an auditable local reward ledger,
  seventeen interactive tutorial lessons, practice, and an original puzzle set.
- Saved games, completed-game review, filters, statistics, and fifteen
  one-time achievements.
- Persisted settings, light/dark themes, accessibility controls, documented
  Developer Options, local export/import, and confirmed data resets.
- Thirty-three locale options with 934-message parity and three RTL locales.
  English is the reviewed source; all 32 other packs are English fallback
  drafts, not completed native translations.
- A single creator/contact website replacing the old social links, regression
  tests, protected signing configuration, and source-release policy checks.

## Build and verify

Use the pinned Flutter 3.44.7 / Dart 3.12.2 baseline from CI. Install Android
Studio and the documented SDK/JDK prerequisites, then run:

```text
flutter pub get --enforce-lockfile
dart run tool/generate_locale_fallbacks.dart --check
flutter gen-l10n
flutter analyze
flutter test --coverage
dart run tool/verify_chess_domain.dart
dart run tool/generate_source_sbom.dart --check
dart run tool/verify_release_readiness.dart
flutter build apk --debug
```

The debug build is for local testing, not public distribution. See
[Android build evidence](android_build.md), the [test matrix](test_matrix.md),
and [release status](release_status.json) for the recorded verification scope.
The optional relay requires Node.js 24 or newer; run `npm ci`, `npm run check`,
and `npm test` from `server/`. Configure your own trusted relay URL for friend
play; no public relay is provided or contacted by default.

## Important limits

No APK, AAB, signing key, or native Stockfish executable is included. Computer
play uses the built-in bounded Dart engine, not a bundled Stockfish binary.
The five-puzzle catalog is intentionally small. System sounds/haptics depend
on the device. Device-clock-based rewards are not tamper-proof. The relay
operator can observe live room traffic.

Physical-device accessibility and performance qualification, native translation
review, owner-controlled signing, final human legal review, and any Play Store
submission remain open. **A stable GitHub source tag does not mean these checks
passed, and it does not certify production Android readiness.** No external gate
has been silently marked passed. See the full
[known limitations](known_limitations.md) and
[remaining qualification steps](../upcoming/next.md).
